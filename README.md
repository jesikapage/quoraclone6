# 🚀 Qoora Clone
**Platform Berbagi Pengetahuan & Q&A**

Selamat datang di repositori proyek **Qoora**. Aplikasi ini dirancang sebagai platform berbagi pengetahuan dengan antarmuka yang modern, responsif, dan performa tinggi yang dibangun di atas *runtime* **Bun**.

---

## 🛠️ Tech Stack
* **Runtime:** [Bun](https://bun.sh) (v1.3.8)
* **Backend:** [ElysiaJS](https://elysiajs.com/) (Web Framework)
* **Frontend:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
* **Database:** [Neon PostgreSQL](https://neon.tech/) (Prisma ORM)
* **Cloud:** AWS Lambda (Backend) & AWS CloudFront (Frontend)
